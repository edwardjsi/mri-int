# CAI Knowledge Dictionary

> **Every investment decision in CAI must be traceable back to one or more canonical observations defined in this dictionary. If an observation is not defined here, it cannot be consumed by a rule, generate evidence, contribute to an inference, or influence a portfolio decision.**

This document is the master registry of all permissible terminology and data points within the CAI ecosystem. It ensures that technical, fundamental, portfolio, and market data remain perfectly deterministic.

## Observation Definition Schema

Every observation defined in this dictionary adheres to the following metadata schema:

```yaml
Observation ID: OBS-XXX-000
Name: [Human readable name]
Category: [Technical | Financial | Management | Industry | Portfolio | Market]
Subcategory: [Raw | Derived]
Data Source: [e.g., Quarterly Results, Market Data Feed]
Data Type: [Percentage | Boolean | Float | Integer | String]
Frequency: [Daily | Weekly | Quarterly | Annual | Event-Driven]
Generated By: [Financial Extractor | Technical Engine | etc.]
```
