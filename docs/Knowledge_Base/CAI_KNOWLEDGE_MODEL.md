# CAI Knowledge Model v1.0

> **Every investment decision in CAI must be traceable back to one or more canonical observations defined in this model. If an observation is not defined here, it cannot be consumed by a rule, generate evidence, contribute to an inference, or influence a portfolio decision.**

This document defines the formal ontology, schema, and taxonomy for the CAI ecosystem. It separates the **Data World** (facts and metrics) from the **Reasoning World** (evidence and decisions).

## 1. The CAI Reasoning Pipeline

```text
Raw Data
    │
    ▼
Extractors
    │
    ▼
Metrics
    │
    ▼
Observations
    │
    ▼
Rules
    │
    ▼
Evidence
    │
    ▼
Inference
    │
    ▼
Hypotheses
    │
    ▼
Policies
    │
    ▼
Resolution
    │
    ▼
Decision
```

## 2. Observation Type vs. Instance

CAI distinguishes between the definition of an observation (the dictionary) and the specific occurrence of an observation in time (the database). 

### Observation Type Schema (The Dictionary)
```yaml
Observation ID: OBS-FIN-004
Name: Revenue Growth
Category: Financial
Data Type: Percentage
Unit: %
```

### Observation Instance Schema (The Database)
```yaml
Observation ID: OBS-FIN-004
Stock: Granules
Value: 24.3
Unit: %
Observation Date: 2026-Q1
Effective Date: 2026-04-15
Source: Quarterly Results (Table 4, Column Revenue)
Confidence: 100%
Generated By: Financial Extractor
```

## 3. Canonical Observation Types

### Technical (Raw Metrics vs Observations)
* `OBS-TEC-001` EMA20 (Metric)
* `OBS-TEC-002` EMA50 (Metric)
* `OBS-TEC-003` Weekly Close (Metric)
* `OBS-TEC-101` EMA20 Rising (Observation)
* `OBS-TEC-102` Price above EMA20 (Observation)
* `OBS-TEC-103` Higher High (Observation)
* `OBS-TEC-104` Higher Low (Observation)

### Financial (Raw vs Computed vs Observations)
* `OBS-FIN-001` Revenue (Raw Metric)
* `OBS-FIN-002` EBITDA (Raw Metric)
* `OBS-FIN-101` Revenue Growth (Computed Metric)
* `OBS-FIN-102` Operating Margin (Computed Metric)
* `OBS-FIN-201` Revenue Growth Accelerating (Observation)
* `OBS-FIN-202` Margin Expanding (Observation)

### Semantic Observations (LLM Extracted)
* `OBS-SEM-001` Management Confidence Improved
* `OBS-SEM-002` Execution Risk Rising
* `OBS-SEM-003` Demand Visibility Weak
* `OBS-SEM-004` Pricing Power Strengthening
* `OBS-SEM-005` Customer Concentration High

### Portfolio
* `OBS-PTF-001` Position Weight
* `OBS-PTF-002` Target Weight
* `OBS-PTF-003` Sector Weight
* `OBS-PTF-004` Cash Available
* `OBS-PTF-005` Number of Tranches

*(Note: Higher-level constructs such as "Trend Strengthening", "Bull Regime", and "Liquidity Tightening" have been properly elevated out of the Observation layer and now belong downstream in the Evidence or Inference layers).*
