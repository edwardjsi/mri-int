# 1. PRODUCT OVERVIEW

## Product Name

# PERX — Institutional Rerating Intelligence Engine

---

# Core Purpose

PERX is an orchestration layer built on top of existing MRI/STEE/QIF systems.

It does NOT replace:

* MRI,
* STEE,
* QIF,
* Risk Audit,
* Digital Twin,
* existing CAGR framework.

Instead, it synthesizes all engines into:

# a unified institutional rerating intelligence report.

---

# Primary Product Goal

Answer this question:

> “Is institutional market perception changing in a way that could lead to sustained PE rerating?”

---

# Product Positioning

NOT:

* stock screener,
* signal platform,
* AI stock picker,
* trading terminal.

INSTEAD:

# Institutional Equity Intelligence System.

---

# 2. EXISTING SYSTEMS (DO NOT MODIFY)

# Existing Engines Must Remain Intact

| Engine        | Role                             |
| ------------- | -------------------------------- |
| MRI           | Technical leadership             |
| STEE          | Elite technical setup validation |
| QIF           | Business quality engine          |
| Risk Audit    | Existing holdings analysis       |
| Digital Twin  | Portfolio tracking               |
| Debate Engine | AI forensic review               |
| Regime Engine | Market environment               |

---

# Critical Constraint

DO NOT:

* change signal generation logic,
* alter CAGR framework,
* disturb existing production flows,
* dilute signal scarcity.

The rarity of signals is intentional and desirable.

---

# 3. NEW PRODUCT LAYER

# PERX = ORCHESTRATION + SYNTHESIS

PERX consumes:

* deterministic engine outputs,
* qualitative engine outputs,
* sector intelligence,
* narrative analysis.

Then generates:

# a unified institutional rerating report.
